# Flying Bird — v2.4 · Приглашения и следы

Это **патч для уже установленной структуры v2.3**. Архив намеренно
**не содержит `src/config/runtime.js`**, чтобы не перезаписывать уже настроенный
Realtime Database URL. Firebase Rules менять не нужно.

## Что исправлено

1. Удалены публичные редакторы URL из Multiplayer и Friends. Firebase автоматически
   подключается через существующий `src/config/runtime.js`.
2. После успешного входа в комнату приглашение получателя удаляется из
   `multiplayerInvites/<recipientUid>/<roomCode>`. Список также подписывается на
   состояние приглашённых комнат и очищает записи удалённых комнат, когда игрок
   открыл Multiplayer. Приглашения с истёкшим сроком тоже очищаются.
3. Следы в сетевой гонке используют реальные движущиеся частицы из палитр и
   специальных функций одиночной игры (FIRE, WATER, LIGHTNING, RAINBOW, NATURE,
   GOLDEN, FROST, STARDUST, SHADOW, AURORA, HEART). Учитываются режимы
   качества частиц и настройки эффектов.

## Установка (Mac, корень репозитория ~/Flappy-bird)

Сначала сделай резервную копию проекта. Скачанный ZIP распакуй в корень
репозитория с заменой только одноимённых файлов. Например:

```bash
cd ~/Flappy-bird
unzip -o ~/Downloads/Flying_Bird_v2_4_Safe_Update.zip
npm run check
git add index.html package.json src/game/solo.js src/firebase/friends.js src/multiplayer/multiplayer.js README_UPDATE_v2_4.md
git commit -m "Multiplayer v2.4 - invitations and trail effects"
git push origin main
```

Если архив скачан под другим именем или в другую папку, поправь путь
во второй команде. Render должен продолжать публиковать директорию `.`.

## Проверка после деплоя

1. У двух аккаунтов должен работать вход в Multiplayer без настройки URL.
2. Пригласите второго игрока: приглашение отображается, пока комната открыта.
3. Примите приглашение и войдите — оно исчезает из списка и из RTDB.
4. Создайте другое приглашение, затем удалите комнату: у получателя
   приглашение исчезнет при открытом списке или при следующем входе в Multiplayer.
5. Проверьте FIRE, AURORA и HEART в гонке, переключите Particle Quality.

### Ограничения

Реальное удаление приглашения, когда получатель не открывал игру,
будет выполнено **при его следующем подключении**. Для немедленной очистки
офлайн-получателей без его участия нужна серверная Cloud Function или
отдельная серверная процедура.

Косметика удалённой птицы видна, только если её тип следа известен клиенту
(например, опубликован вместе с профилем). В данной версии схема RTDB-матча
не меняется, поэтому обязательной передачи экипировки всем соперникам нет.
